# 2.0 staging release · 27 November 2026

* Repaired the public demo directory, retained the homepage hero, and placed five branded synthetic demo environments beneath their residences.
* Added reusable student, management, maintenance, security, transport and housekeeping portals. Operational and demo pages use separate data adapters and the same accessible components.
* Moved new backend settings to `assets/config.js`. Added a common API layer, directory URLs, tab-aware legacy redirects, authenticated account pages and explicit onboarding/pilot gates.
* Preserved six landing, questionnaire and admin routes; restored the compatible eKaya management layout and incorporated the recent staff multi-capture patch.
* Added isolated operations workflows, SQL, a private optional vault, transaction-based occupancy/stock updates, a read-only DULA review and a migration register for legacy calls.
* Replaced older walkthrough recordings with three sample-only clips and included English captions for the two homepage players.
